# Manual-RPM - Patient Monitoring System

**Simplified Patient Monitoring for Healthcare Teams**

## Overview

Manual-RPM is a complete remote patient monitoring dashboard built with the MERN stack (MongoDB, Express, React, Node.js). It digitizes patient vitals tracking with smart reminders, automatic alerts, and shareable reports.

## Tech Stack

### Frontend

- React 18.2+ with Vite
- Tailwind CSS
- Shadcn/UI Components
- React Router v6
- Axios
- Recharts (Data visualization)
- Framer Motion (Animations)

### Backend

- Node.js 18+ with Express.js
- MongoDB Atlas (Free Tier)
- Mongoose ODM
- JWT Authentication
- bcryptjs for password hashing

### Deployment

- Frontend: Vercel
- Backend: Render
- Database: MongoDB Atlas

## Features

- ✅ JWT Authentication
- ✅ Patient Management (CRUD)
- ✅ Vitals Entry with Templates (General, Cardiac, Diabetic)
- ✅ Automated Alert System
- ✅ Smart Reminders with Scheduler
- ✅ Secure Sharing with QR Codes
- ✅ PDF/CSV Export
- ✅ Trend Visualization
